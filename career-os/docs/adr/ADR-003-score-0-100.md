# ADR-003 — Score 0–100 como camada derivada
Status: aceito e implementado (2026-11-05, `packages/core/src/matching`). Requisito desconhecido recebe 25% do peso (nunca conta como atendido); <60% dos componentes avaliáveis limita a categoria a "moderada". O career-ops pontua 1–5 via LLM. O Career OS calcula um score 0–100 **determinístico** (pesos em YAML versionado, componentes explícitos, "desconhecido" ≠ "atendido") e, quando existir relatório A–H, incorpora o 1–5 como um componente. Gates duros: autorização de trabalho e idioma obrigatório não atendidos → categoria `blocked`, independente da soma.
